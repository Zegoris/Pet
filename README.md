# Тамагочи — C++20 Modules

## Архитектура

- `include/` — объявления классов, структур, перечислений и интерфейсы именованных модулей `.cppm`.
- `src/` — определения методов классов и реализация модулей в `.cpp`.
- `main.cpp` — единственная точка входа.
- `main.py` — конфигурация CMake, сборка и запуск.
- `CMakeLists.txt` — настройка проекта и набора модулей C++20.

## Классы

`Pet`, `NeedsSystem`, `GameWorld`, `Inventory`, `Storage`, `AchievementManager`, `Game`.

## Возможности

Показатели питомца, настроение, кормление, игры, уход, лечение, тренировки, сон,
время и случайные события, монеты, магазин, инвентарь, уровни, достижения,
сохранение и загрузка.

## Требования

CMake 3.28+, компилятор с поддержкой C++20 named
Рекомендуется использовать актуальные версии MSVC или Clang и Ninja.

## Запуск

```bash
cmake -S . -B build -G Ninja
cmake --build build
./build/tamagotchi
```

## Принцип разделения

Каждый файл `include/*.cppm` является интерфейсной единицей именованного
модуля и содержит публичные объявления. Соответствующий файл `src/*.cpp`
является единицей реализации этого же модуля (`module tamagotchi...;`) и
содержит определения методов. Реализация не подключает интерфейс через
`#include`: связь обеспечивается системой модулей C++20 и сканером зависимостей
CMake. Это принципиальное отличие от старой схемы с текстовым включением
заголовков.
